# Portfolio

Omar Reda's personal portfolio site. Next.js (App Router) + TypeScript + Tailwind CSS.

See [`CLAUDE.md`](./CLAUDE.md) for project conventions, design tokens, and current phase
status, and [`implementation-plan.md`](./implementation-plan.md) for the full roadmap.

## Development

```bash
npm run dev           # start the dev server
npm run lint           # ESLint
npm run format:check   # Prettier check
npm run build           # production build
```

Internal design-token reference (not linked in site navigation): `/dev/style-guide`.
